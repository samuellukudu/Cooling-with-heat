Cooling with heat — one simulation per application, by hand

Each page below is a standalone hand-written HTML file in docs/simulations/. No Python generator, no embedded solver replay: every simulation is a small explicit finite-difference / lumped model in vanilla JS, with that application's own setpoints, fluid band, geometry and heat source hard-coded. Open any file straight from disk — no server, no dependencies.

Physics twins used live in the pages: Magnus/Antoine saturation pressure, Watson latent heat, Dubinin–Astakhov uptake (adsorption pages, same correlations as harness.physics.thermo), Novikov 3-temperature COP with concentration spread (absorption page, same form as harness.physics.absorption). Constants are printed on each page so you can check them.

6 · Absorption chiller (LiBr/H₂O — heat-to-cooling cousin)

T_evap 7 °CT_cond 30 °CT_gen slider 55–120 °CLiBr-H₂O / NH₃-H₂O

The liquid-sorption sibling of the adsorption beds: generator → condenser → evaporator → absorber with a solution loop. Novikov ideal COP derated by pair effectiveness; drag T_gen down to 55 °C and watch circulation (Δx) die — the band-bottom degeneracy, live.

How to read the heat-flow diagrams

On every page: amber = waste/solar heat IN (Q_in), cyan = cooling delivered (Q_cool), grey = heat rejected to ambient (Q_rej = Q_in + Q_cool, energy balance). Arrow widths are proportional to the live computed powers — change a slider and watch the balance shift. COP = Q_cool / Q_in always.
