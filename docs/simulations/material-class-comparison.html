Material class comparison — all anchor materials on one cycle

Every material from adsorbent-ml/data/anchors.csv evaluated on the same equilibrium cycle. The D–A isotherm parameters drive the uptake; the class determines the regeneration window and Q_st.

1 · The cycle

T_evap = 16 °C, T_cond = 35 °C, T_des = 60 °C (datacenter profile — the hard low-grade case). Half-cycle 300 s. hx = 1.35. All 13 anchor materials evaluated live with the same Magnus/Watson/D–A physics. The table is sorted by COP; the bar chart shows Δq (working capacity) and COP side by side.

materialclassq_satQ_stEnΔqCOPSCPwindow

The class story: zeolites bind too hard (need >130 °C regeneration), MOFs are tunable but expensive, silica gel is the workhorse, salt composites have high Q_st but slow kinetics. The D–A fit window is shown — out-of-window materials are extrapolated (flagged).
